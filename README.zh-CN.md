# AI标题生成

一个替你给笔记起名的思源插件。选中一篇或多篇笔记，插件按你配置的接口（Chat Completions、Responses API、Anthropic Messages 或 Gemini Interactions）请求标题，然后直接写回，或者先交给你确认。

## 为什么做这个

思源把新建文档命名为「无标题」。之后重命名是件手工体力活，而给一整个文件夹的笔记逐个改名繁琐到多数人干脆放弃。

这个插件把这道工序自动化：读取每篇笔记的正文，向模型请求标题，再通过内核自己的标题接口写回——文档路径、子文档路径和搜索索引都保持同步。

## 功能

- **批量生成。** 在文档树中选中多篇笔记，一次完成。笔记会自动切分批次，批次之间并发执行。
- **写回前先确认。** 每个标题都可编辑：取消不想要的，改动任意一条，或单独重新生成一行。
- **四种协议。** Chat Completions、Responses API、Anthropic Messages 与 Gemini Interactions。可对接任意兼容服务，也可直接导入思源里已配置好的供应商——协议跟着一起导入。
- **直接使用思源里配好的供应商。** 新装的默认选项：协议、地址、密钥与请求头都用思源里那一份。
- **可调思考强度。** 从「禁用」一直到最高档，也可以完全不发送、交由供应商决定。
- **API Key 加密落盘。** 用思源自己的数据仓库密钥加密后再写盘；没有数据仓库密钥时退回明文保存，并在设置页里标出来。

## 环境要求

- 思源 3.8.3 或更高版本。
- 一个支持 Chat Completions、Responses API、Anthropic Messages 或 Gemini Interactions 的接口及其 Base URL 与 API Key，**或者**思源里已经配好的 AI 供应商。

## 安装

1. 从思源集市搜索`ai-title-siyuan`安装本插件。
2. 或从 [最新发行版](https://github.com/wmy2981/ai-title-siyuan/releases/latest) 下载 `package.zip`，然后在思源中打开 **设置 → 集市 → 已下载**，点击 **从安装包安装**，选择该 zip，之后启用插件。

自行构建：

```bash
git clone https://github.com/wmy2981/ai-title-siyuan.git
cd ai-title-siyuan
npm ci
npm run build
```

产物 `package.zip` 会出现在仓库根目录。

## 配置

打开 **设置 → 集市 → 已下载 → AI标题生成 → 设置**。

1. **协议** —— 默认 **使用思源设置中供应商**：协议、地址、密钥与请求头都按思源里选中的那条来。想自己填这些值，改成下面四个具体协议之一。这一项每台设备各存一份，不参与数据同步。
2. **供应商** —— 只在上面选了 **使用思源设置中供应商** 时出现，从思源已配置的供应商里挑一个；列表为空说明思源那边还没配过。
3. **Base URL** —— 自定义协议下按你所用供应商的文档带上版本段。Messages 协议填到 `/v1` 即可，插件自己补 `/messages`；Interactions 协议填到 `/v1beta` 即可，插件自己补 `/interactions`。
4. **API Key** —— 接口无需密钥时留空；保存前会用思源的数据仓库密钥加密，见下文。
5. **模型名称** —— 可直接输入，点击 **获取模型列表** 从供应商端点选择，或用 **从思源设置获取** 复制你已配置好的供应商。选中思源供应商时，点输入框会列出该供应商登记的模型。
6. 点击 **测试连接**。有回复就说明配置可用。

### 自定义请求头

有些供应商要求请求带上自己的请求头。opencode 就是其中之一：它要求每段对话在 `x-opencode-session` 里发送一个稳定的会话 ID，并使用客户端专属的 `User-Agent`。在 **自定义请求头** 里按 JSON 对象填写即可：

```json
{
  "x-opencode-session": "{{vars.OPENCODE_GO_SESSION}}",
  "User-Agent": "my-agent/1.0"
}
```

- `{{vars.名字}}` 取 **设置 → 密钥和变量** 里的变量，`{{secrets.名字}}` 取密钥，都在**每次请求前**替换 —— 插件只存引用文本，因为变量可能被别的插件按会话改写。
- 密钥受它自己的「允许主机」约束：目标主机不在列表里时占位符原样保留，密钥不会被发到没授权给它的端点。变量没有这层限制。
- 查不到的名字原样保留。在供应商的报错里看到 `{{vars.…}}` 本身，说明变量名写错了或还没配。
- 与插件自己发出的头同名时以这里为准（例如用请求头而不是 **API Key** 传 `Authorization`），因此这时 **API Key** 可以留空。
- 名字必须是合法请求头名、取值必须是字符串，且大小写不敏感地不许重复；写坏了保存时就会提示。
- **从思源设置获取** 会把供应商的请求头一起复制过来（该按钮只在自定义协议下出现）。思源 3.8.4 起供应商才有这个字段，更早的版本里导入结果就是空的。

### API Key 的存储

**API Key 会用思源自己的数据仓库密钥加密之后再写进插件数据目录。**

- 密钥取自 **设置 → 数据仓库密钥**，插件在本地做 AES-256-GCM 加密，明文不落盘。
- **没初始化过数据仓库密钥时无法加密**（思源不会自动生成它），这时退回明文保存，并在 **API Key** 那一行的说明里写出来。
- **重置或更换过数据仓库密钥后旧密文解不开**：插件清空已存的 Key 并提示一次，重新填写即可。
- 通过 `http://局域网IP:6806` 用浏览器打开思源时没有加密能力，密文会原样保留，但这一次要重新填一遍 Key，落盘的也是明文。
- 旧版本存下的明文 Key 会在插件加载时自动改成密文，不需要手动操作。
- **自定义请求头不加密**，里面要放密钥请用 `{{secrets.名字}}` 引用思源的密钥库。

### 标题的应用方式

| 档位             | 单篇笔记   | 多篇笔记   |
| ---------------- | ---------- | ---------- |
| **禁用**（默认） | 弹确认窗口 | 弹确认窗口 |
| **仅单篇笔记**   | 直接写回   | 弹确认窗口 |
| **总是**         | 直接写回   | 直接写回   |

批量改名是破坏性操作，而思源的重命名没有撤销栈。**批次请求失败时仍会先弹确认窗口**——那种情况下有一部分笔记没拿到标题，值得先看一眼再决定要不要应用其余的。

标题可以使用行内 Markdown。思源 3.8.10 起，带行内 Markdown 的标题会按标题源写入，粗体、斜体、代码和链接按样式显示；原本是普通标题的文档会在这种情况下升级成富文本格式（旧版客户端可能读不了这篇文档），标题不含 Markdown 时仍按普通重命名、格式不变。旧版思源存不了富文本标题，写回前先去掉标记。生成的标题与当前标题文字相同时保持原样，否则整体替换。

## 使用

四个入口，行为一致：

- **顶栏按钮**：为当前正在编辑的笔记生成标题。
- 编辑器内的 **面包屑按钮**：同上。
- **在文档树中右键笔记**：为一篇或多篇生成标题。批量走这里。
- **命令面板**中的 _用 AI 生成标题_。

## 排查

在设置里开启 **调试模式** 并打开 console，可看到完整请求体、原始响应和每步流程决策。

| 现象                                                              | 多半是                                                                                                                                                                                                                                                                                               |
| ----------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `HTTP 404`                                                        | Base URL 写错。Messages 填供应商的 Messages 基础地址（Anthropic `https://api.anthropic.com/v1`，DeepSeek `https://api.deepseek.com/anthropic`），Interactions 带上版本段（如 `https://generativelanguage.googleapis.com/v1beta`）。插件只在缺失时补 `/v1`、`/messages`、`/v1beta`、`/interactions`。 |
| `HTTP 401`                                                        | API Key 错误或缺失。Messages 认 `x-api-key`，除 OpenRouter 外插件都按这个头发送。                                                                                                                                                                                                                    |
| `HTTP 400` 且提到未知参数                                         | 供应商不认 `reasoning_effort`。把 **思考强度** 设为 **默认**。                                                                                                                                                                                                                                       |
| 报错里出现 `max_completion_tokens`                                | 供应商只认 `max_tokens`。插件会自动改名重试；看到两次说明重试也失败。                                                                                                                                                                                                                                |
| `SiYuan provider "…"` 类报错                                      | 供应商已从思源里删除、当前角色读不到思源 AI 配置、没填 Base URL，或它用的协议插件没实现。到思源 **设置 → AI** 补齐，或在插件里改选一条。                                                                                                                                                             |
| `SiYuan has no default model …`                                   | 选了 **跟随编辑器默认** / **跟随智能体默认**，但思源那一处还没设默认模型。到 **设置 → AI** 设一个。                                                                                                                                                                                                  |
| 请求头里 `{{vars.…}}`、`{{secrets.…}}` 原样发出                   | 名字不存在，或该密钥的「允许主机」不含 Base URL 的域名。                                                                                                                                                                                                                                             |
| `Anthropic thinking needs an output token limit of at least 2048` | 开了思考档位，但 **最大输出 token** 不到 2048。调大它，或把 **思考强度** 设为 **默认**。                                                                                                                                                                                                             |
| 模型没有返回任何内容                                              | 推理可能耗尽了输出预算。调大 **最大输出 token**，或把 **思考强度** 设为 **禁用**。                                                                                                                                                                                                                   |
| 标题不是我想要的语言                                              | 修改 **标题语言**，它默认跟随思源界面语言。                                                                                                                                                                                                                                                          |
